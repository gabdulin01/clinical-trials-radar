# Contributing

Thanks for helping improve Clinical Trials Radar.

1. Fork the repository and create a focused branch.
2. Run `npm test` and `npm run check` before opening a pull request.
3. Describe the user-facing change and include screenshots for visual changes.
4. Do not commit patient information, API credentials, or proprietary datasets.

Please keep medical claims out of the interface. ClinicalTrials.gov records describe studies; they do not prove that an intervention is safe or effective.
